# Careeros 🎯

A **personal career management platform** that keeps every part of a job search organized in one place — applications, interviews, networking, and skill growth.

**🔗 Live demo:** [liciashow.github.io/Careeros](https://liciashow.github.io/Careeros/)

## ✨ Features

- **Job application tracker** — log every application and its status
- **Kanban board** — move roles through stages visually
- **Interview logger** — record interviews and takeaways
- **Follow-up reminders** — never miss a check-in
- **Networking tracker** — keep tabs on your contacts
- **Skill gap analysis** — see what to learn next for your target roles

## 🧰 Built with

- **HTML** — structure
- **CSS** — styling and layout
- **JavaScript** — interactivity and data handling

## 🚀 Run it locally

1. Clone or download this repository
2. Open `index.html` in any web browser

No installation or setup needed — it runs right in the browser.

## 💡 About this project

I built Careeros to solve a real problem I had — keeping a job search organized across applications, interviews, and networking. It turns a messy, stressful process into a clear system, and gave me hands-on practice building a multi-feature front-end app.
